# Name and logo policy (draft)

The code is free software; the name and logo are not part of its licenses. This policy exists for one reason: so that nobody can ship a modified, tracker-filled or stealth build that people mistake for the real app.

> **Draft.** It isn't legal advice, and the project hasn't registered a trademark. Other, unrelated apps also use the name Kinfold; this policy covers only this project's name and swallow logo.

## You may, without asking

- Say that your software is compatible with, or based on, Kinfold.
- Use the name to refer to the project in articles, reviews, talks and teaching.
- Run unmodified official builds and call them Kinfold.
- Use the name and logo in unmodified screenshots.

## You may not

- Distribute a modified app, server or web companion under the Kinfold name or with the swallow logo. Forks must use a different name, a different icon, and their own app IDs and push credentials.
- Use the name or logo in a way that suggests the project endorses you or your service.
- Use a confusingly similar name or icon for a location-sharing product.

## Hosting

Running an unmodified Kinfold server for your family, friends or community is fine; please don't call your service "Kinfold" in a way that suggests it's run by the project.

Questions: open an issue.
