An independent JavaScript implementation of Kinfold v0 (draft 0.3), written from `spec/PROTOCOL.md` alone. `kinfold.mjs` uses only WebCrypto, so it also runs unchanged in a browser.

From the repository root, run `node reference/js/verify.mjs spec/vectors/kinfold-v0.json` with Node 22 or later. No npm install is needed. A relative path also resolves against the repository root, and with no argument the script checks the vectors in the repo.

It prints a pass count per group (about 5,000 checks), lists every failure, and exits with status 1 if anything fails. Besides checking every vector as a client and as a server, it rebuilds each main-log entry, envelope, link message and push byte for byte from the seeds (where the platform's Ed25519 signatures don't repeat, as in WebKit, §3.3, up to the signature, which must verify), and tests things the vector file can't hold: fresh random round trips, a client that is missing an epoch secret or holds a wrong one throughout the main log, payloads held while private state is frozen, and both sides of every payload limit.

**Ed25519.** `verifyRaw` makes the three byte checks of §3.3 itself and only then calls WebCrypto. They are needed: on Node 22, WebCrypto alone accepts 17 of the 23 edge-case signatures that every implementation must refuse, among them every small-order public key. The script prints that count for the platform it runs on.

**Signatures that don't repeat.** §3.3 lets an implementation's Ed25519 signatures differ each time, and WebKit's WebCrypto adds randomness to each, as CryptoKit does. The script signs one message twice to find out. Where the two differ, it checks each structure it signs again against the vector up to the signature at its end, and checks that the new signature verifies with the validator that parses the whole structure. `KINFOLD_SIGNATURES_REPEAT=0` takes that path on a platform whose signatures repeat, which tests it.
